# Phase A チェックリスト — Lumina Notes 感性対話刷新

更新日: 2026-08-09  
位置づけ: 実装前ゲート。**v1 必須** / **v1.1 やるとよい** / **将来** の3段。

---

## ゴール

- **v1**: AI を「採点者」から「伴走者」へ。本人の写真との対話（AWARENESS）をプロンプト・表示で一貫させる。
- **v1.1**: 将来の `audience`（第三者・展示／コンテスト）や brief 駆動ルーブリックを妨げない最小の拡張点。
- **将来**: 製品形態（別アプリ vs モード）・動的評価軸・モデル移行は後続波で判断。

識別子の直交（方針）:

| 識別子 | 意味 | v1 |
|--------|------|-----|
| `mode` | `compact` / `full`（生成の深さ） | 既存どおり |
| `lens` | `self` /（将来 `audience`）対話の型 | **常に `self`**（UI 非公開） |
| `rubric_source` | （将来）`brand_fixed` / `brief_generated` | 未実装・概念のみ |

## Phase D（応答評価）— v1 ルーブリック（`self`）

実 API。オフライン CI では行わない。観点 ID で記録する。

| ID | 観点 | 合格の目安 |
|----|------|------------|
| D-role | 役割 | 採点者口調ではなく伴走・編集者 |
| D-score-meaning | スコア意味 | 技術出来ではなくアンテナの向き／純度 |
| D-axis-names | 項目名 | 新5軸で出力・カード一致 |
| D-title | タイトル | 被写体名ラベル・時間帯単語なし、仮説的 |
| D-summary | 短評 | 無意識の意図への仮説／対話のきっかけ |
| D-person | 人物 | しぐさ・視線・物語（点ではない） |
| D-exif | EXIF | 心の揺れ／曖昧さの肯定。禁止語なし |
| D-advice | アドバイス | 問いかけで循環（数値指導の締めではない） |

将来の `audience` / brief 駆動は **別表**（企画適合＋ブランド下限）とする。
