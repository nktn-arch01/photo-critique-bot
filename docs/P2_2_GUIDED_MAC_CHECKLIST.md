## ステップ3 — ブラウザ画面を確認する（選ぶ）

**操作**

1. 先に **読む** と **振り返る** タブを開く → 案内文が出る（空状態）  
2. **選ぶ** に戻り、**「写真を選ぶ」** をクリック  
3. Mac 上の JPEG 写真を1枚選ぶ  
4. **選んだ写真のプレビュー**がドロップゾーン内に表示される  
5. その下に **パラメータ一覧**（画像情報・カメラ設定）が表形式で表示される  
6. **読む** → **振り返る** → **選ぶ** の順でタブを行き来する。戻ったあと **写真を選ぶ** と **言葉にする** が押せる  

> **補足:** GPS が無い写真でも `region` / `time_band` はタイムゾーンから推定されます（例: `東京` / `正午（九）`）。  
> **3e / 3f の Mac 操作は未確認です。** Linux の自動テストでは、タブ移動ともう一度は講評を cancel しない、隠した画面だけ inert、と固定しています。

## ステップ4 — 画面遷移と講評（API キー必須）

> **初回:** 下記の API キー設定を済ませてから進んでください。

1. 写真を選ぶ  
2. **言葉にする** を押す → **読む** 画面へ  
3. 数十秒以内に **タイトル・短い言葉・もう少し長い言葉** が表示される（待ちのあと）  
4. **観察の輪郭** を開くと ★ の行が見える  
5. しばらくすると **情景描写** などのプルダウンが増える（Phase2 完了後）  
6. **もう一度** → **選ぶ** に戻る。**写真は残る**  
7. **クリア** → 写真とパラメータ一覧が消える  
8. 再度写真を選び **言葉にする** → **この言葉を残す** → **振り返る**  
9. **カードプレビュー**（写真＋言葉入り）が表示される。下に「書き出したときに、このプレビューは更新されます。」がある  
10. **フォルダを選ぶ** は表示されない（削除済み）  
11. 星 **☆☆☆☆☆** → タップで **★** → **振り返りメモ**（気づいたこと等）にチェック・入力  
12. **Noteに書き出す**（右寄せ）→ フォルダ選択 → `{ファイル名}_LN.png` と `{ファイル名}_LN.md` の **2ファイルのみ**（サブフォルダは作らない）  
13. 書き出し成功後、画面下にトースト（「書き出しました」）が出て **振り返る** に留まる（選ぶへは移らない）。次回は **前回の保存先** が初期表示される

| 4b | もう一度 | 写真が残る |
| 4c | 読む配置 | 画像→Compact→ボタン→観察の輪郭→【1】以降 |

## うまくいかないとき（コピペ一発）

### python3 がない

[python.org](https://www.python.org/downloads/) から Python 3 をインストール後、ステップ2を再実行。

### ポートが使用中

```bash
cd ~/photo-critique-bot && GUIDED_WEB_PORT=8766 bash scripts/run_guided_web.sh
```

ブラウザは `http://127.0.0.1:8766/` を開く。

### 表示が古いまま（改修が反映されない）

ターミナルに次を **まとめて** 貼り付けて Enter。前のサーバは自動で止まり、最新で起動し直します。

```bash
cd ~/photo-critique-bot
git fetch origin
git checkout cursor/p2-2-web-concept-f193
git pull origin cursor/p2-2-web-concept-f193
bash scripts/run_guided_web.sh
```

ブラウザは **⌘ + Shift + R**。それでも古いときは、そのタブを閉じてターミナルが開いた新しい画面を使ってください。

### すでに起動中

同じ起動コマンドをもう一度実行すると、前のサーバを止めて最新のプログラムで起動し直します。
