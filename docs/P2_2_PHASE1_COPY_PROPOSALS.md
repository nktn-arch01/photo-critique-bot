常時表示する本文（これ以外の長文ヘルプは公開時不要）:

```text
画像を選ぶお手伝いをします。
対象フォルダ：
　対象とするオリジナル画像のフォルダ（月別／イベント別）を選んでください。
選ぶプロセス：（公開版はM1,M2,M3の選択不要。全て実行）
　残す=撮影ミスと思われるもの以外を残す
　見返す=言葉にする候補を残す
　言葉にする=画像から読み取れる印象（気付き・感情・記憶）を言葉にする
結果をJPEG Ratingの星の数で示します
　残す=1、見返す=2、印象に残る=3、印象に強く残る=4
　対話ノートを作成する画像を選ぶ目安にしてください
```

## 実装時の注意（合意確認用）

1. **公開 Guided UI** では段チェック（M1/M2/M3）を出さず、内部は全段実行。  
2. **Console（パワー）** に段チェックを残すか → 次の返信で指示ください（案: 残すがラベルは A6–A8）。  
3. Rating 星の意味は B の説明どおり（1=残す … 4=印象に強く残る）。内部パイプライン値との対応を実装で固定。  
4. `(i)` 吹き出しは Guided UI（Phase 3 以降）で検討。Console は説明枠の全文のみでも可。
