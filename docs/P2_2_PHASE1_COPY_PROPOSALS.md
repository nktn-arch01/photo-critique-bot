## B. スクリーニング・ヘルプ本文（U4 / Q7 / S3）

### B1 — タブ説明（現行）

```text
流れ（このタブだけ）: 候補付け →（任意）カード → 閉じると DxO 差分を自動記録
Lumina Review は隣のタブ（独立・必須ではありません）

オリジナルの月／イベントを選び、候補の Rating を付けます。
月の配下イベントは既定で対象外。必要なときだけ下のチェックをON。

Rating（パイプライン状態。DxO の「出来の星」とは別）:
  0=除外 / 1=M1 / 2=M2 / 3=余白 / 4=上位

Works への置き方（アプリはコピーしません）:
  …
```

### B1 — 改訂案

```text
ここでは「残す」候補に目印を付けます（採点ではありません）。
隣のタブ「言葉にする」は必須ではありません。

オリジナルの月／イベントを選んでください。
月の配下イベントは、必要なときだけ下のチェックをON。

目印（アプリ用。DxO の「出来の星」とは別）:
  0＝外す / 1＝足切り通過 / 2＝熱を感じる / 3＝余白 / 4＝特に残したい

M2「熱量」とは: この並びのなかで、いま熱を感じるコマ（相対）。正しさの順位ではありません。

Works への置き方（アプリはコピーしません）:
  …
```

### B2 — 監査・カード枠（現行）

```text
DxO で Rating を直したあとの差分は、ウィンドウを閉じるときに自動で残します（手動操作は不要）。
「カード」は Rating 3/4 の JPEG に Phase1 カードを付け、説明欄へ TITLE 等を書き込みます。
```

### B2 — 改訂案

```text
DxO で目印を直したあとは、ウィンドウを閉じるだけで差分が残ります（操作不要）。
「言葉のカード」は、特に残したいコマ（目印 3／4）に短い言葉を載せ、写真の説明欄にも書きます。
```

## C. Works／言葉にする・ヘルプ（U4 / S3）

### C1 — タブ説明（現行）

```text
Works 月フォルダの JPEG に対話ノート／カードを付けます。
常にカード＋詳細ノート（【1】〜【7】）。
説明に TITLE 等があるコマはカードを作り直しません（ノートは作成）。
スクリーニング無しでも、ここに画像があれば単独で実行できます。
ファイルのコピーはしません。

Works は YYYYMM のみ（例: ~/2026/202606）。
同一コマは {stem}_dev.jpg を優先（撮って出し除外は確認時に表示）。

Works への置き方（アプリはコピーしません）:
  …
```

### C1 — 改訂案

```text
ここでは Works の写真を見返し、言葉にし、もう一度見られるようにします。
カード（短い言葉）とノート（【1】〜【7】）を付けます。
すでに説明欄に言葉があるコマは、カードを作り直しません（ノートは付けます）。
「選ぶ」をしていなくても、Works に写真があればここだけ使えます。
ファイルのコピーはしません。

Works は月フォルダ名 YYYYMM のみ（例: ~/2026/202606）。
同じコマは {stem}_dev.jpg を優先します。

Works への置き方（アプリはコピーしません）:
  …
```

### C2 — Works 置き方ガイド（`works_placement_guide_text`・現行）

```text
Works への置き方（アプリはコピーしません）:
  オリジナルで選ぶ → DxO で直す／現像 → {stem}_dev.jpg を Works 月フォルダ（例: ~/2026/202606）直下へ
  RAW は置かない。撮って出し .jpg だけでも可（_dev があれば優先）
```

### C2 — 改訂案

```text
Works への置き方（アプリはコピーしません）:
  オリジナルで残す候補を付ける → DxO で直す／現像 → {stem}_dev.jpg を Works 月（例: ~/2026/202606）直下へ
  RAW は置かない。撮って出し .jpg だけでも可（_dev があれば優先）
```
