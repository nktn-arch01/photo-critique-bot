## レビュー1 — 不正な状態を表せない

講評は写真セッションの中に1つだけある。世代（`epoch`）が今の仕事。古い世代の書き込みは捨てる。

| 状態 | 意味 |
|------|------|
| `idle` | 写真はある。まだ「言葉にする」していない（またはクリア直後はセッション自体が無い） |
| `running` + epoch | Phase1 または Phase2 の最中 |
| `complete` + epoch | 残せる |
| `error` + epoch | 失敗。写真は残る。同じセッションでもう一度「言葉にする」できる |
| （セッション無し） | クリア・タブ閉じ・成功した写真差し替えのあと |

**作らない組み合わせ**

- 進行中なのに `idle`（「キャンセルして止めた」見かけ）
- タブを隠しただけで世代を進める
- ダイアログの Cancel と講評の破棄を同じ言葉にする
- 壊れた写真やピッカー Cancel で、今の写真セッションを捨てる

ユーザー操作 → 効果は次の表だけ（コードの `effect_for` と同じ）。

| 操作 | 効果 | 講評 | 写真 |
|------|------|------|------|
| タブ移動 | `noop` | 続く（読むに戻ったら続きを見る） | 残る |
| もう一度 | `noop` | 続く | 残る |
| 写真ピッカー Cancel | `noop` | 触らない | 残る |
| 壊れた写真 | `noop` | 触らない | 残る |
| 書き出し Cancel | `noop` | 触らない（完了のまま） | 残る |
| ページの戻るキャッシュ | `noop` | 触らない | 残る |
| 言葉にする | `supersede` | 新しい epoch でやり直す | 残る |
| 詳しい言葉を再取得 | `supersede` | Phase2 だけ新しい epoch | 残る |
| クリア | `destroy` | セッションごと消える | 消える |
| 写真の差し替え成功 | `destroy`（古い方） | 古いセッションごと消える | 新しい写真 |
| タブを閉じる / ページ離脱 | `destroy` | セッションごと消える | 消える |
| 書き出し成功 | `noop`（講評は完了のまま） | 残る | 残る。画面は振り返る |

`inert` は画面の表示の話。講評の世代とは別。隠した画面だけ inert。いま見ている画面は inert にしない。

書き出しのフォルダ選択は `picked` / `cancelled` / `unavailable`。`cancelled` は Tk に落とさない。

## レビュー2 — 一本化（対症療法を削る）

以前は「選ぶが死ぬ → cancel する」「Phase2 待ちで固まる → cancel しない」と、同じ cancel を反対向きに足していた。

いまの一本:

1. **画面を動かす**（タブ・もう一度）= 講評を触らない。ポーリングは止めない。隠した画面は inert。
2. **やり直す**（言葉にする・Phase2 再取得）= epoch を進める。cancel API は使わない。
3. **捨てる**（クリア・差し替え成功・タブ閉じ）= セッションを消す。消えたセッションへの書き込みは無視する。cancel してから idle にはしない。

クライアントの `/critique/cancel` 呼び出しは削除する。サーバの cancel 端点はテスト用の世代無効化として残してよいが、画面操作の正本ではない。
