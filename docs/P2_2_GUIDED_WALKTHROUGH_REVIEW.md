## 結論

Guided は **ローカル専用（127.0.0.1）** の 3 画面アプリとして、講評の状態機械・一時ファイル・Vision API 最小化は揃っている。チェック 0–5 と 4i はオーナー PASS。

残るのは「壊れる」系統ではなく、**設計どおりの残リスク**が主である。今すぐ必須の修正は、ブラウザ応答に載っていた未使用の識別情報を外したこと（下記レビュー）。

---

## 1. 一貫性

| 項目 | 判定 | メモ |
|------|------|------|
| 講評操作 | よい | 効果は noop / supersede / destroy のみ。画面は `/critique/cancel` を呼ばない |
| 写真の失敗 | よい | 壊れたファイルは成功時だけ差し替え。既存を先に捨てない |
| 書き出し Cancel | よい | `cancelled` と `unavailable` を混ぜない。講評は complete のまま |
| 起動 | よい | 古いプロセスを止めて差し替え。前面プロセス（Control+C） |
| 3画面の体験 | よい | クリア全消去、書き出し後は振り返る、トースト、空状態 |
| 死んだ応答フィールド | **直した** | `original_path` と `local_meta_preview` は JS 未使用なのに HTTP に出ていた。サーバのセッションには残す（書き出し MD 用） |
| cancel API | 許容 | 画面は使わない。テスト用の世代無効化として残る |

## 2. 構造（シンプルさ・堅牢さ）

```text
ブラウザ 3画面
  → 127.0.0.1 FastAPI
      → セッション（メモリ）+ /tmp/lumina_guided
      → ピッカー（osascript / Tk は unavailable のときだけ）
      → 講評（epoch + lock、Vision は EXIF 除去 JPEG + 抽象パラメータ）
      → 書き出し（選んだフォルダへ _LN.png / _LN.md）
```

潜在エラーで **再現しうるが、いま止まらないもの**

| 内容 | 深刻度 | 扱い |
|------|--------|------|
| 写真に GPS があるとき、都市名のために OpenStreetMap（Nominatim）へ位置を問い合わせる | 中（プライバシー。アプリは落ちない） | 構想どおり。OpenAI には生 GPS を送らない。残リスクとして記録 |
| ブラウザの別サイトから `127.0.0.1:8765` へリクエストを飛ばす（読むことは CORS で難しい） | 低 | この Mac だけで動かす前提。トークン認証は未実装 |
| `/critique/cancel` が残っている | 低 | 画面からは呼ばない |
| 永続 `session.json`（P5）が無い | 低 | クラッシュするとメモリ上の講評は消える。書き出し済み MD は残る |
| アップロードサイズ上限が無い（T4 延長） | 低 | 巨大ファイルでメモリを食う可能性。任意 |

講評の途中操作・タブ・クリアは状態機械とオフラインテストで固定済み。

## 3. プライバシー

二重経路（構想 §7）は守られている。

| 送る先 | 送るもの | 送らないもの |
|--------|----------|----------------|
| **OpenAI** | EXIF を除いた圧縮 JPEG、抽象パラメータ、任意の一言 | フルパス、生 GPS、機種名、IPTC 全文 |
| **OpenStreetMap Nominatim**（GPS がある写真だけ） | 緯度経度（都市名に変換） | 画像・一言・パス |
| **この Mac** | 一時 JPEG、設定、監査 JSONL、書き出し MD（パス・EXIF ブロック含む） | — |

監査ログ `~/.lumina_notes/guided_api_audit.jsonl` は許可キーと一言のハッシュのみ。

ブラウザの選ぶ画面に出す表は抽象パラメータ（ファイル名・日時・地域・時間帯・カメラ設定）。機種名・生 GPS は出さない。

**今回直したこと:** 写真アップロード／ピッカー成功の JSON から、画面が使っていない `original_path` とメタ抜粋を外した。フルパスはサーバ側セッションにだけ残し、Note 書き出しに使う。
