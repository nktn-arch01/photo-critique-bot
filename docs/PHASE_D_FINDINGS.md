## 1. 「P02 が ModifyDate 23:16 を拾っている」仮説

### 実測（修正前コードでも）

| タグ | P02_light.jpg |
|------|----------------|
| `DateTimeOriginal` | **2025-11-12 05:45:22**（撮影） |
| `ModifyDate` | 2025-11-13 23:16:19（現像・編集と一致） |
| アプリ `date_time` | **05:45:22** |
| アプリ `time_zone_fact`（旧） | **早朝・黎明（日の出前後）** |

→ **コードは ModifyDate を採用していなかった。** ユーザー仮説の「23:16 を拾っている」は、このファイルについては成立しない。

### ではなぜ「夕景」「夜」が出たか

| 経路 | メタデータ | 実際の挙動 |
|------|------------|------------|
| **Compact = Phase1 のみ** | 日時を**渡していない**（規則5） | 暗い建物を見て視覚的に「夕景」とラベル（禁止語違反） |
| **Full の Phase1** | 同上（別 API 呼び出し） | TITLE「夜の静けさを映す」＝視覚推定 |
| **Full の Phase2** | 正しい 05:45 / 旧「早朝・黎明」を注入 | 本文に「早朝の光」— Phase1 の「夜」と**同一レスポンス内で矛盾** |

**根本原因:** 撮影時刻の誤読ではなく、**(A) Phase1 の視覚的時間帯ハルシネーション**と、**(B) `time_zone_fact` ラベル自体に「夕景」「黄昏」「夜間」が入っており禁止語を AI に教えている自己矛盾**（特に P04 は旧ラベルがそのまま「夕景・黄昏…」）。

## 2. Compact と Full で Phase1 が大きく違う

設計上、`mode=compact` と `mode=full` は**それぞれ独立に Phase1 API を呼ぶ**（Full は続けて Phase2）。  
`temperature` 既定 0.7 のため、同じ画像でも TITLE / SCORES / 短評が毎回変わる。

LINE で同一画像を簡易→詳細と送ると、カードの軸が別物に見えるのは**仕様バグに近いUX問題**。

### 対策の段階

| 段階 | 内容 | 状態 |
|------|------|------|
| すぐ | Phase1 の temperature を下げる（0.35） | **実装済** |
| 次 | 同一画像の Phase1 を content-hash でキャッシュし、full は再利用 | 未着手（要設計） |
| 製品 | 「詳細は簡易カードを拡張する」UX を明示 / スコアをフィルターに使わない | 方針確認待ち |

## 3. スコアが講評のたびに変わる（フィルターに使えない）

期待と実装のギャップ:

- 免責文どおり ★ は「良し悪しの点数」ではなくアンテナのスナップショット
- 実装は非決定的サンプリングのため、**保存して後から絞り込みするキーには不向き**

安定フィルターが必要なら、別指標（ユーザー★、タグ、日時、レンズ固定ルール等）か、温度0＋キャッシュ＋再生成禁止が必要。Phase D 課題として記録。

## 4. 人物写真が1枚・Compact が人物無視

- 評価セットの人物スロットは P01 のみ（統計的に弱い）
- Phase1 に人物ルールはあったが強制力が弱く、Compact が人物を無視し得た

**対策:** Phase1 ルールを「TITLE か CRITIQUE_SUMMARY で視線・しぐさ・佇まいに必ず触れる」へ強化（実装済）。Phase D に人物写真を追加して再評価推奨。

## 5. 3段階レビュー結果（今回のコード対策）

### レビュー1（根本）

- 撮影時刻: **DateTimeOriginal のみ**（ModifyDate / CreateDate 不採用）を明示化
- `time_zone_fact` を禁止語なしの時計帯ヒントへ変更（自己矛盾の除去）
- Phase2: 時計帯と視覚印象の優先関係をプロンプトで固定
- Phase1: 暗い画面での夜/夕推測禁止、人物必須言及

### レビュー2（一貫性）

- 単一ソースは引き続き `scanner.py` / `critique_prompts.py` / `critique_engine.py`
- ARCHITECTURE 規則5を上記に合わせて更新

### レビュー3（テスト・発展）

- オフライン: 時計帯ラベルに禁止語が無いこと、P02 が DateTimeOriginal 05:45 になること
- 将来: Phase1 キャッシュ（画像ハッシュ）、スコア安定化は製品判断のうえ別タスク
